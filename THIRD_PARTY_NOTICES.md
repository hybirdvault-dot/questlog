## Apache-2.0 components

- **nowinandroid** (Android Developers) — architecture and UX patterns.
- **Mihon** (Mihon) — Compose and architecture patterns.
- **ML Kit samples** (Google) — on-device ML usage patterns.
- **mobile-wallet-adapter-clientlib** (Solana Mobile) — Mobile Wallet Adapter client used for wallet authorization and transaction signing.
- **web3-solana** (Solana Mobile) — Solana transaction and public-key primitives.
- **rpc-core** (Solana Mobile) — JSON-RPC client core for Solana.
- **multimult** (funkatronics) — Base58 encoding/decoding.
- **OkHttp** (Square) — HTTP client.
- **Retrofit** (Square) — typed HTTP client for the RAWG API.
- **Coil** (Coil Contributors) — image loading.
